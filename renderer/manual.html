动作触发一览

动作怎么触发表现
🧘 待机什么都不做（默认状态）待机1 / 待机2 两套动画随机交替循环
👋 挥手打招呼鼠标左键单击宠物单爪抬起挥手，播完回到待机（1.2 秒内连点不重复触发）
🏃 跑开奔跑鼠标在宠物身上一次性划过约 200px（来回划也可以）朝远离鼠标的方向跑开一段距离；向右跑用默认素材，向左跑自动左右镜像
🤔 审阅思考WPS、Excel 等办公软件处于前台时（右键单击也可触发）进入审阅动画；完整播完一次后冷却 20 秒再自动重播，切走办公软件回待机
🫳 抓起拖拽左键按住并拖动（移动超过 6px 即算拖拽）跟手移动；抓起动画播完定格在最后一帧，松手落下回待机/审阅

提醒与托盘

・托盘图标（通知区）右键：培养手册 / 控制面板 / 显示隐藏宠物 / 退出
・宠物右键菜单同样可打开培养手册与控制面板
・控制面板里添加带时间的提醒，到点后系统通知 + 宠物头顶冒文字泡泡
・控制面板中的 「下载崩溃日志」：按钮带红点说明有未下载的崩溃记录，下载成功红点消失

想调整参数？

动作速度 / 优先级 / 冷却 → renderer/pet.js 顶部 BEHAVIORS / COOLDOWN；
体型缩放（0.75 倍等）→ renderer/pet.js 的 ACTION_VISUAL；
跑开灵敏度 / 距离 → config.json 的 interaction；
完整速查表见项目 README.md（所有可改参数都带 ★ 注释）。
